## 2. Search Console "Missing field" flags — `uploadDate` (Videos), `startDate` (Events)

**Backlog entry**: `BACKLOG.md`, "Reliability, ops & cost" → "Search
Console, structured data & SEO plumbing" (grep `New "Missing field"
flags`). Tagged `[NEEDS-AUDIT]`, not `[HUMAN]` — included anyway because
it's a pure dashboard-read step and this routine's brief says to scan
this subsection regardless of tag.

**Background** (from the entry, plus one correction found re-verifying
today): a 2026-08-21 code fix made a page with a null/unparseable `date`
emit *neither* `uploadDate` nor `startDate` in its structured data,
instead of emitting an invalid value — trading Search Console's old
"invalid datetime value" flag for a new "missing field" flag on the same
underlying pages. The flag first appeared in Search Console 2026-08-31.
The entry says "how many real pages this affects is unconfirmed" — **that's
now only half true**: `BACKLOG_DONE.md`'s 2026-08-29 "Search Console
dashboard walkthrough" entry shows `GET /internal/date-format-audit` was
actually run two days before the flag appeared and found **226 pages
with a null date out of 2,389 total** (rest were clean `YYYY-MM-DD`,
zero malformed). That's a real, if two-days-stale, starting number for
Step 2 below — worth adding to the `BACKLOG.md` entry itself once this
is checked, since the entry currently reads as if no count exists at
all.

**Step 1 — Google Search Console → Videos enhancement report.**
Go to `search.google.com/search-console`, select the
redtaperecordings.com property. In the left sidebar under
"Enhancements," click **Videos**. Look for an issue row reading
**"Missing field 'uploadDate'"** and note its **Affected items** count.
- **0 or not listed**: the gap isn't showing up as a live issue today —
  nothing to do; worth noting the entry as low-priority/closeable.
- **A nonzero count**: compare it loosely to the 226-null-date baseline
  above. Roughly in that range confirms the known trade-off and nothing
  new; a much bigger number is worth a fresh `/internal/date-format-audit`
  run (needs the `ARCHIVE_INGEST_TOKEN` bearer token) before deciding
  whether to backfill, fix per-adapter date capture, or accept the gap.

**Step 2 — Google Search Console → Events enhancement report.**
Same property, left sidebar "Enhancements" → **Events**. Look for
**"Missing field 'startDate'"** and note its **Affected items** count.
Same read as Step 1.

No further UTC/local-time conversion needed here — the dates involved
