## A7. Zoom recording pilot (5 links). Do first; it is quick.
`scripts/tier3_auto_transcription_queue_probe.csv` has 21 distinct `zoom.us/rec/share` links. Sidney MT's is also in the tier-3 queue. Pick 5, from different governments. Open each in the repo's headless browser (`fetch_headless_sync`) and record:
- Does it play without sign-in?
- Is there a direct video file URL?
- Is a passcode required?
- Does Zoom show its own transcript or captions?
- The recording date.

Zoom's robots.txt disallows `/rec/*` for crawlers. These are person-approved links, so a one-time check is fine. Do not build any crawl.

Report: one row per link, then yes or no on "an adapter is feasible".

## A9. ChampDS embed test. Also quick.
Our player cannot play VOD2 streams, because the stream demands `Referer: https://play.champds.com/` (`app/platforms/champds.py`, about lines 270-280).

Test whether a play.champds.com event page can be shown inside an iframe on another site, and whether it can seek to a start time:
1. On 2 or 3 real event pages from different tenants, check `X-Frame-Options` and CSP `frame-ancestors`.
2. Load a tiny local HTML page with the iframe in the headless browser. See whether it plays.
3. See whether it accepts a time parameter. Look for one in the player's URL or JS.

Report: yes or no, with the evidence.

3. For each page, run the window check at three points: early, middle and late. Record:

Report: a table "Result | Count of 100", with the rows aligned, constant offset, drift or step, and could not check. Attach the CSV.
